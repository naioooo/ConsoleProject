## 게임 개요

- **게임 이름 :  2D Shooting Game**
- **개발 인원 : 1명**
- **개발 기간 : 2주**
- **개발 환경 : Visual Studio**
- **개발 언어 : C++**
- **게임 소개 :** 계속 생성되는 적을 무찌르고 아이템을 얻어 성장하고 보스몬스터를 처치하세요
- **콘솔 사이즈** : 130 x 30
- **맵 사이즈** : 60 x 20
- **게임 플레이 방법**
    1. Space를 통해 게임을 시작한다
    2. 게임은 총 3스테이지와 보스스테이지로 이루어져 있다
    3. 우측 칸에는 플레이어의 상태와 정보가 있고 킬카운트를 모두 채울 시 다음 스테이지로 이동한다
    4. 플레이어는 움직이며 기본공격과 우측의 asd키를 이용해 스킬을 사용할 수 있다
    5. 몬스터를 죽이며 모든 스테이지를 클리어 한다면 승리
- **조작법**

     **방향키 :** 캐릭터의 상, 하, 좌, 우 이동

     **Control :** 플레이어의 총구 방향 설정

     **A, S, D :** 스킬 사용

     **Q, W, E :** 스킬 구매
